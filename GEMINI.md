# Project Rules — dashboard-mevi

## Verification & Command Execution
- **Do NOT run `flutter analyze`, `dart analyze`, `flutter test`, `dart test`, or any other static analysis / unit test suite automatically** after completing code changes, unless the user explicitly asks to run them in their message.
- Verify changes by carefully checking syntax, imports, types, and edited lines directly in the files.
- Only run build, analyze, or test commands when explicitly requested by the user.
